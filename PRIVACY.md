# ICS Language Tools Privacy Notice

ICS ships as a separate extension for each supported editor, and the notices
differ because the products differ: the VS Code extension obtains its .NET
runtime through the Microsoft .NET Install Tool, while the Visual Studio
extension bundles a self-contained converter and downloads nothing.

Please read the notice for the editor you use:

- [ICS for VS Code](./privacy/vscode.md)
- [ICS for Visual Studio](./privacy/visual-studio.md)

Common to both: source conversion, language services, recovery data, and
diagnostics run entirely on your machine. Source code, file names, and file
paths are never transmitted. Only user-requested licence activation,
validation, and deactivation contact Lemon Squeezy, and error reports are
prepared locally for your review and sent only if you choose to send them.

[Product terms](./TERMS.md), and the
[Activation transfer and deactivation policy](./LICENSE-TRANSFERS.md).
